Verification notes record static source and link checks; browser behavior and live database integration were not tested as part of this documentation update.

The current application uses Express, MongoDB/Mongoose sessions and data, EJS pages under views/, and vanilla JavaScript/CSS served from public/. server.js mounts JSON APIs under /api and document routes at /; routes/pages.js defines the routes listed above. Protected routes recheck account roles in middleware/auth.js; shared query helpers live in utils/queries.js. The /editorial and /technology prototype redirects have been removed. See README.md for setup and DESIGN.md for styling conventions.
